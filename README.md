# book_Manager

## Overview
Railsを用いて作成した書籍管理Webアプリケーションです。<br>
CRUD(Create,Read,Update,Delete)機能を用いて実装しています。<br>
所有している漫画や書籍を管理することを目的としており、タイトル・著者・出版社・巻数・メモなどを登録できます。<br>
また完結/未完結の設定や絞り込みや、タイトル検索機能なども実装してます。<br>

## Sytem Overview
本システムはUnityプロジェクトのみで構成されています。
