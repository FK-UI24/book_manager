# book_Manager

## Overview
Railsを用いて作成した書籍管理Webアプリケーションです。<br>
CRUD(Create,Read,Update,Delete)機能を用いて実装しています。<br>
所有している漫画や書籍を管理することを目的としており、タイトル・著者・出版社・巻数・メモなどを登録できます。<br>
また完結/未完結の設定や絞り込みや、タイトル検索機能なども実装してます。<br>

## Sytem Overview
本システムはこのリポジトリだけで動作します。
本システムはRailsのMVCモデルに基づいて構成されています。
- Model：書籍データ管理
- View：画面表示
- Controller：CRUD処理および検索処理

## Feature
- 書籍データの登録・編集・削除(CRUD機能)
- タイトル検索機能
- 完結/未完結フィルタ機能
- 巻数管理機能
- メモ機能
- タイトル順ソート
